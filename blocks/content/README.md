# blocks/content

Seções que existem para serem lidas ou percorridas.

## Categorias previstas

`blog-component` · `gallery-component` · `timeline-component` · `portfolio` ·
`article-body`

## Regras

- Hierarquia de título correta: um `h1` por página, sem pular níveis.
- Medida de leitura confortável no corpo de texto — em torno de 65 caracteres
  por linha.
- Galeria precisa de texto alternativo obrigatório na assinatura, não opcional.
