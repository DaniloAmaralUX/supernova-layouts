# blocks/marketing

Seções de página que existem para convencer alguém.

## Categorias previstas

`hero-section` · `cta-section` · `features-section` · `pricing-component` ·
`testimonials-component` · `faq-component` · `logo-cloud` · `social-proof` ·
`team-section` · `statistics-component` · `compare`

Uma pasta por bloco, dentro desta. O nome da pasta é o nome do item.

## Regras

- Todo texto de exemplo em português do Brasil.
- Nenhuma imagem de terceiros. Use marcação de espaço com `bg-muted` ou um
  ícone do `lucide-react`.
- O bloco recebe conteúdo por propriedades; nada de texto fixo no meio do JSX
  sem um valor padrão declarado na assinatura.
