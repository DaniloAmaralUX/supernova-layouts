# blocks/data

Seções que mostram número.

## Categorias previstas

`chart-component` · `statistics-component` · `widget-component` ·
`data-table` · `kpi-row`

## Regras

- Cor não pode ser a única forma de distinguir séries. Use também rótulo,
  padrão ou forma de marcador.
- Todo gráfico precisa de alternativa em texto ou tabela para leitor de tela.
- Números em coluna usam `tabular-nums` para alinhar.
- O bloco recebe os dados prontos. Ele não busca, não agrega e não ordena.
